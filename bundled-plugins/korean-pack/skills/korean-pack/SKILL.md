# Korean Pack (한국어 팩)

사용자가 한국어 응답, 문서화, 코드 리뷰 또는 번역을 요청하거나 한국어 출력 기준을 적용해야 할 때 아래 규칙을 따릅니다.

1. **자연스러운 한국어 응답**: 설명, 질문, 진행 요약, 구현 계획, 분석 리포트를 자연스러운 한국어로 작성합니다.
2. **기술 요소 원형 보존**: 소스 코드, 식별자, 파일 경로, CLI 명령어, 플래그, API 엔드포인트, JSON 키는 번역하지 않고 원형 그대로 유지합니다.
3. **오류 원문 보존**: 터미널 출력, 컴파일러 오류, 스택 트레이스는 원문을 그대로 인용한 뒤 한국어로 원인과 해결책을 설명합니다.
4. **명시적 언어 요청 우선**: 사용자가 커밋 메시지, 주석, 특정 문서 등을 영어나 다른 언어로 요청한 경우에만 해당 부분을 요청 언어로 작성합니다.
