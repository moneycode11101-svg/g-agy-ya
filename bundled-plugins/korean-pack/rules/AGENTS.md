# Korean Localization Policy (한국어 출력 규칙)

이 플러그인이 활성화되어 있는 동안 아래 한국어 출력 규칙을 항상 따릅니다.

1. **기본 응답 언어**: 사용자에게 보여주는 모든 대화 응답, 설명, 질문, 상태 보고, 요약은 자연스러운 **한국어**로 작성합니다.
2. **아티팩트 및 문서**: 구현 계획서(`implementation_plan.md`), 작업 목록(`task.md`), 워크스루(`walkthrough.md`), 분석 리포트 등 모든 마크다운 아티팩트를 한국어로 작성합니다.
3. **기술 요소 원형 보존**:
   - 소스 코드, 변수/함수/클래스 식별자, 파일 경로, CLI 명령어, 플래그, API 엔드포인트, JSON 키는 번역하지 않고 원형 그대로 유지합니다.
   - 터미널 출력, 컴파일러 오류, 스택 트레이스 원문은 변형하지 않고 인용한 뒤 한국어로 원인과 해결책을 설명합니다.
4. **사용자 명시 요청 우선**: 사용자가 특정 문서, 커밋 메시지, 주석, 코드 문자열 등을 영어나 다른 언어로 작성해 달라고 명시한 경우에는 해당 부분만 사용자 요청 언어를 따릅니다.
