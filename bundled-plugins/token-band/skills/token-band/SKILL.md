# Token Band

사용자가 토큰밴드, 컨텍스트 사용량, 캐시 읽기/쓰기 효율, 도구별 토큰 증분, 또는 쿼타 확인을 요청하면 `open_token_band` MCP 도구를 호출해 사이드 패널 대시보드를 열고 핵심 지표를 간결하게 안내하세요.

- 현재 대화를 분석할 때는 현재 `conversationId`를 전달하거나 생략(최신 대화 자동 선택)합니다.
- 매 턴 채팅창에 자동 표시되는 1줄 인라인 HUD 설정(켜기/끄기, 도구 호출마다 표시 여부, 일간 예산)은 사이드 패널의 **HUD 설정** 탭에서 바로 변경할 수 있습니다.
